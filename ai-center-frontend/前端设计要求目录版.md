# 前端设计要求目录版

按设计问题或界面上的英文名称定位章节。跨模块改动先读通用原则，涉及具体页面时再读该模块细则。规则正文见[《前端设计要求》](./前端设计要求.md)。

## 按设计问题查通用原则

| 设计问题 | 检索词 | 正文入口 |
|---|---|---|
| 用户从哪里进入，怎样返回原处？ | 顶栏、侧栏、同级菜单、标签、返回、导航状态 | [导航与层级](./前端设计要求.md#principles-navigation) |
| 一个动作应放在什么位置？ | 单对象、跨资产、目录操作、行操作、多个入口 | [操作对象与入口](./前端设计要求.md#principles-actions) |
| 怎样减少页面占位并看清层次？ | 标题、外框、留白、边界对齐、筛选区、结果区 | [布局与信息密度](./前端设计要求.md#principles-layout) |
| 数据或选项变多后怎样浏览和选择？ | 目录树、搜索、分页、跨页勾选、层级弹窗、批量导入 | [规模与选择方式](./前端设计要求.md#principles-scale) |
| 哪些字段可以分别修改？ | 独立维度、多选、可选属性、按类型展示表单 | [属性与表单](./前端设计要求.md#principles-fields) |
| 去哪里配置、试用和检查结果？ | 配置、预览、执行、测试范围、运行详情 | [配置与运行流程](./前端设计要求.md#principles-workflow) |
| 操作后怎样知道影响及结果？ | 批量工具栏、按钮顺序、尺寸、归档、删除确认、失败反馈 | [操作与反馈](./前端设计要求.md#principles-feedback) |
| 怎样兼顾主题、键盘和触屏？ | 深色、语义用色、图标文字、键盘焦点、窄屏、减少动态效果 | [视觉与交互](./前端设计要求.md#principles-accessibility) |
| 同一种交互在哪个目录实现和复用？ | 功能菜单、子目录、组件、单项与批量 | [代码组织](./前端设计要求.md#implementation) |
